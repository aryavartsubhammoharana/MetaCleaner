Privacy Policy

Effective Date: 2026

At MetaCleaner, absolute user privacy is the foundational design principle. We run a strict zero-log, zero-retention service.

1. Zero Storage Policy

Uploaded files are handled purely in ephemeral memory and transient temporary directories. No files are indexed, categorized, archived, or permanently stored on disk.

2. Immediate Destruction on Download

The moment you click the download link, the server initiates an automatic system-level deletion sequence that purges both the uploaded source and the cleaned copy from server storage.

3. Automated Pruning Sweep

Any temporary files that are uploaded but never completed or downloaded are automatically erased by server sweepers after 15 minutes.

4. No User Tracking or Profiling

There are no registration portals, tracking cookies, analytics pixels, or database entries logging your IP address or session details.
